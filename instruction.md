# Copilot Instructions

## Code Style
- Use clean, modular Python code
- Follow PEP8
- Use functions and classes where appropriate
- Add comments for logic-heavy sections

## Structure
- Separate logic, routes, and UI
- Keep Sudoku logic independent from Flask

## Features
- Support difficulty levels (Easy, Medium, Hard)
- Ensure Sudoku has ONE unique solution
- Add timer, hint, check, scoreboard

## UI
- Responsive design (mobile + desktop)
- Support dark mode
- Highlight 3x3 grids with alternating colors

## Error Handling
- Handle invalid inputs gracefully
- Provide clear feedback to users
